With many variables in play, string sizing can be a complicated process. Yaskawa – Solectria Solar will walk you through how to properly calculate the optimal PV string length and array size. After reviewing how these calculations are performed, we will demonstrate our easy to use online String Sizing Tool. You will have an easy time customizing your project details, including modules and weather data specific to your project location. After attending this webinar, you will be equipped with all you need to know how to properly size your PV system by hand and with Yaskawa – Solectria Solar’s easy to use String Sizing Tool.
