Easy to DIY Canvas Stretcher Bar System.
Grab a pair of scissors. No professional tools necessary. (e.g. pliers, glue, right angle corner clamp, etc.)
Note The size of the frames that you order will not equal to the size of your entire canvas. You need to leave an extra 1.75 - 2 inches on each side of the canvas to install the frame strips (the size of the frame you order must be smaller than the size of the canvas, and an additional 3.5 - 4.0 inches canvas must be used to wrap around the frame).
At any scale. Please send your request to orders@plartprint.com
