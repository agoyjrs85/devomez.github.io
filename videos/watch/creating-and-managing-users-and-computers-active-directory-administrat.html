This video is a step by step guide demonstrating how to administrators can manage their directory service objects by using the new Active Directory Administrative Center.

The version of Active Directory Administrative Center that is included in Windows Server 2012 has additional
improvements, including a Windows PowerShell History Viewer to help you learn Active Directory cmdlets.
For more information, see Active Directory Administrative Center Enhancements.

Create new user accounts
Create new groups
Create new computer accounts
Create new organizational units (OUs)
