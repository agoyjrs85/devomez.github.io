Learn to how to make a robe for yourself or your bridal party by following the steps in this DIY tutorial. In this video, I show you how I make my satin robes or silk robes using a pattern.

Please note that no seam allowance has been added to the pattern. All allowances will be added while cutting the fabric.

Watch the how to draft the robe pattern here: https://youtu.be/vNQeam5GLW4

Here’s how to make a single fold bias tape or double fold bias tape https://www.youtube.com/watch?v=bzD6UvBiJGY

Recommended Measurements can be found here: https://drive.google.com/file/d/1i8UR_WveiIt1l7gKy9VRoBbYzHGGd8Xf/view?usp=sharing

RECOMMMENDED FABRIC QUANTITY (36 inches make a yard and fabric length is 60 inches):
Size 6-10: 2 Yards
Size 12-16: 2.5 Yards
Size 18-22: 3 Yards

RECOMMENDED BELT LOOP POSITION
Size 6-8: 4.5" - 7"
Sizes 10-14: 5" - 7.5"
Sizes 16-22: 5.25" - 7.75"
