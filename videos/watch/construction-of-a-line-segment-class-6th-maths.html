You might have heard the word “line” in maths very often. But do not confuse yourself with a line and line segment. Both the terms differ from one another. A line has an arrow at the end which means it can extend forever. While a line segment has a distinct beginning and an end.

If you want to travel from one place to another the map will show you the precise beginning and end. The game called “treasure hunt” too has a start and an end point. All of this can be represented with a line segment.

Now that you know about line segment lets learn how to construct it.
