In this tutorial, we will walk through different types of fact. The nature of aggregation of facts for dimensions divides Facts into 3 groups that we can call 3 different fact types:
1. if fact can be summed up for all dimensions in then it is called Additive Fact.
2. if it can be summed up for some dimensions in table but not all then it is semi-additive fact and
3. if it cannot be summed up for any of the dimensions present in the table then it is non-additive fact.
