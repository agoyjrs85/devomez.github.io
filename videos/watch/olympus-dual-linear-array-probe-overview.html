The new Dual Linear Array probe for corrosion inspection from Olympus provides you with many advantages over conventional ultrasonic dual element transducers.

This phased array solution improves productivity through features such as larger beam coverage, faster scan speed, and C-scan imaging with increased data-point density. The pitch-catch technique used by this new probe can offer better near-surface resolution and pit detection in corrosion survey applications than standard phased array pulse-echo, improving probability of detection of critical wall thinning.
