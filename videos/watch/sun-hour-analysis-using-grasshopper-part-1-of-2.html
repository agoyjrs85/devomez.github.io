Previously on my channel, I showed how to use Dynamo and Revit to produce a Sun Hour study for a building form. Grasshopper and Rhino can speed up this process immensely - this video shows how to set up a script to achieve the same outcome. The second part of this mini-series will show how to process and graph the results, as well as omit irrelevant results.
