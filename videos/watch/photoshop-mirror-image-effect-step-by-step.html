To mirror an image in Photoshop, start by opening the image you want to mirror (0:22). Unlock the Background layer (0:34), then add canvas space to both sides of the image (0:57). Add a guide in the vertical center of the document (1:50). Select the Move Tool (2:16), and then drag the part of the image you want to mirror to one side of the guide (2:20). Select the image (2:30), then reshape the selection sing Transform Selection so that only the part you're going to mirror is selected.(2:53). Copy the selection to a new layer (3:40), and the flip the image to mirror it using Free Transform (4:00). Remove the guide (5:07). Then, trim away the extra canvas space with the Crop Tool (5:15). And there we have it! That's how to create a mirror image in Photoshop!
