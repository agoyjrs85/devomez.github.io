Вебинар: Комплексное BIM-решение на основе российского программного обеспечения

Спикер: Нечипоренко Максим Викторович - заместитель генерального директора Renga Software

Целевая аудитория

Проектировщики, архитекторы, инженеры, руководители проектных компаний

Описание

На вебинаре речь пойдет о возможностях программных продуктов АСКОН, Renga Software, 1C и других российских разработчиков для решения BIM-задач. Будет представлен обзор отечественных инструментов, которые позволяют применять технологию информационного моделирования на разных этапах жизненного цикла объектов строительства.

В процессе вебинара будут рассмотрены следующие вопросы:

BIM-система для архитектурно-строительного проектирования Renga
Программное обеспечение других российских разработчиков для реализации BIM-концепции
Взаимодействие программных продуктов разных вендоров между собой
