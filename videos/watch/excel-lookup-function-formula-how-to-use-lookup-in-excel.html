The function LOOKUP in Excel returns a value from range of values (a row or column) or an array. It's an integrated feature in Excel.

𝐋𝐎𝐎𝐊𝐔𝐏 𝐄𝐱𝐜𝐞𝐥 𝐅𝐨𝐫𝐦𝐮𝐥𝐚
--------------------------------------------

Below is the formula of LOOKUP Function

= LOOKUP (lookup_value, lookup_vector, [result_vector])

𝐀𝐫𝐠𝐮𝐦𝐞𝐧𝐭𝐬
----------------------------

Value – The search value.

Lookup vector – A row or range of columns to search for a value. In ascending order, the vector should be sorted.

Result vector – [ optional ] A row or column range that matches the lookup vector and includes the desired output.
