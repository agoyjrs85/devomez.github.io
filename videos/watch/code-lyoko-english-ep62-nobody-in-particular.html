The only way Ulrich will be able to communicate with the others and explain the problem is to possess somebody else’s body – which he does. Once informed and reassured, Jeremy starts programming an application to hunt for Ulrich’s body. But it’s not that easy… especially when XANA ups the ante by starting an attack!
