In this video I unbox a Glacier Bay Market Single-Handle Pull-Out Sprayer Kitchen Faucet. It has a Stainless Steel finish. I also go over all of the hardware that is included and then I show how this faucet works.

The main point of this video is to show you all of the hardware that is included and how you can install this faucet yourself simply by understanding how the faucet hardware works.

I do not do a real install but instead walk you through an imaginary install. If you want to see an example of an actual install for part #1001 813 686 you should subscribe now because I will be posting the real install later.

The thing to keep in mind when watching this video is that this faucet is a single arm or handle faucet. It is made really well since it is made with real stainless steel. It is also convenient because you only need one hole in your sink in order to install this faucet.

I installed this Glacier Bay faucet myself. It has been working great so far. My only complaint is that I had to tighten the faucet once because it started leaking from the spout area. What I like best about this specific model (1001 813 686) is the weight that attaches to the end of the sprayer.

It does not get tangled like my old sprayer did because of the unique weight that comes with it. All of the hardware in this video comes with the faucet. That reminds me, I wanted to mention that it comes with some quick connect fittings which I love.

Here is a list of the included hardware:
Faucet
Sprayer
Weight for Sprayer
Washer / Gasket for the sink and faucet meeting point
Decorative Chrome Cover to hide the washer
Hot water Supply Line
Cold Water Supply Line
Faucet Spray Line
Quick Connect fitting to mount faucet to sink
Quick Connect fittings for the sprayer
