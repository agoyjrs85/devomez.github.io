2:09 - Finding all the passengers without leave the plane

This video contains a guide to finding all the passengers. Even without leaving the plane! + Legit methods as well. This video was made in v0.71 though I will keep the guide updated if any changes are made. Use the guide to complete the achievement the way that suits you. Don't cheat if it's against your values.

Console command method:
1. In the main menu type in developermodeon
2. Start a game, a new one in this case
3. Collect the passenger manifest from the back of the plane
4. Press F1 and type findpassenger 1
5. Press F1 again - This opens the console
6. UP ARROW - This duplicates the last command
7. DOWN ARROW - This goes to the end of the command instead of the start.
8. BACKSPACE - Remove the numbers
9. Then type in the new numbers.
10. Rinse and repeat
