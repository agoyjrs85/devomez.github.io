This decorative cord is easy to crochet as it uses only single crochet stitches! It makes a strong flattened non-stretchy braid with many applications, for example: jewellery, a narrow belt, or a strap for a small bag or purse. A tutorial by June Gilbank (www.planetjune.com).

My method is a simplified variation of the cord used to make Romanian Point Lace. Please note: if you're looking for instructions for Romanian Point Lace cord, this is *not* how to make it!
