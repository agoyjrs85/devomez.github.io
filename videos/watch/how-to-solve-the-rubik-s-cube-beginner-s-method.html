This is a beginner's method for solving the 3x3x3 Rubik's Cube. Throughout this tutorial I will explain how to solve the Cube step by step. This tutorial is recommended for anyone who is learning how to solve the Rubik's Cube the first time.

The following algorithms are used to solve the cube:

3rd layer cross: F, R, U, R', U', F'
Orientating 3rd layer cross: R, U2, R', U', R, U', R', U'
Orientating 3rd layer corners: L', U, R, U', L, U, R', U'
Solving 3rd layer corners: R, U2, R', U', R, U', R', L', U2, L, U, L', U, L
