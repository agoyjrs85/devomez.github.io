The list of vulnerabilities/loopholes are taken from the OWASP (Open Web Application Security Project) top reported website vulnerabailites.

List of loopholes covered in this video:
1. SQL Injection
2. Cross Site Scripting (XSS)
3. Insecure de-serializing (remote code execution)
4. Cross Site Request Forgery (CSRF)
5. Improper security configuration
